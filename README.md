
# Meine Website

## Zweck

Dies ist eine einfache statische Webseite im Rahmen des Unterrichts Webtechnologien. Das Projekt dient dazu, eine Webseite mit HTML zu erstellen und über GitHub Pages zu veröffentlichen.

## Lokal öffnen

Um die Webseite lokal zu öffnen, kann die Datei `index.html` direkt mit einem Webbrowser geöffnet werden.
